# R15 — Cross-sectional escape on a real equity panel

R15 runs the cross-sectional sign monitor on **97 surviving US equities, 2005–2025** (5 154 common
trading days) under two calibrations — an independence assumption and a bootstrap over real null
windows of the panel itself — and races the pooled monitor against a single stream under an
injected drift. It regenerates `articleB_whitening_v87.tex` Figure 17 (`fig:cross_section`) and
every numeral of **L376**, and it discharges **L389**'s printed promise of a public fetcher for the
97 equities, which the repository did not previously carry.

**The escape is real and it is small, exactly as L376 says.** Sign correlation `ρ̂ = 0.2610` (v87
prints `0.26`) saturates the effective panel at `K_eff = 3.74` while `K` grows to 97; the realized
detection budget contracts by **`2.03×`** at `K ≥ 20` (v87 prints "a measured `2×`"); temporal
whiteness of the pooled stream holds up to **`K = 10`** and fails from `K = 20` (v87: "fails beyond
`K = 10`"); the independence null reaches **`99.6%`** false alarms at `K = 40` (v87: "`∼100%` by
`K = 40`"); and the pooled monitor **never** flags the 2020 crash — `delay_boot = −1` at all ten
`K`, a D3-class gate that halts the run if any `K` detects.

**Two printed quantities move and both are registered.** The bootstrap false-alarm envelope
`4.8–6.4%` → **`4.0–5.9%`** under the 128-bit re-keying (`R15-campaign-redraw`, D2; the level is
still held, and both endpoints are extrema over a ten-point grid whose design-corrected standard
errors are larger than the move). The caption's `r ≥ 0.99` is falsified: the measured coefficient
is **`−0.9962`** and is negative at all five drift magnitudes, by construction
(`R15-scatter-sign`, D2).

**One environment difference is isolated to a single variable.** `MKL_CBWR=COMPATIBLE`, set by this
repository's canonical determinism bootstrap and *not* by the submitted campaign, moves
`rho_sign_meas` by at most `3.2e-15` on 7 of 9 cells. Removing it — and nothing else — recovers the
submitted values **bit for bit on all four RNG-free columns at all ten `K`**. Class B, D0, cause
identified (`R15-mkl-cbwr-rho`).


The orchestrator runs the offline provenance stage, then the campaign, then — **unconditionally** —
the `--witness-blas` attribution arm. Running a diagnostic only when a result comes out badly is
how a diagnostic becomes an instrument of selection, so it always runs and its artefacts always
ship, stamped `_witness_blas` and certifying no v87 value.

The network path is **not** in the orchestrator and is not inside any determinism claim:

```bash
./run_experiment_R15.sh --data-source yfinance --stage ingest    # one-off, rate-limited
```

It rebuilds the panel from Yahoo Finance, names every abandoned and every low-coverage ticker, and
**verifies** the result against the committed `data/derived_equities/R15_panel_logreturns.csv`
without overwriting it.

`run_all.sh` discovers `run_experiment_R15.sh` by sorted enumeration; neither `run_all.sh` nor
`run_tests.sh` nor `README.md` is edited by this experiment.

## The panel, and the survival rule that is not the obvious one

`exp_R15_cross_sectional_a.py` is the fetcher L389 promises. Its default stage is **offline**: it
reads the committed CSV, logs its digest, and re-verifies the shape and the date span. Its `ingest`
stage hits the network sequentially with the delivered pacing (`SLEEP_S = 2.0`, `MAX_RETRY = 3`),
carries `UNIVERSE` and `auto_adjust=True` verbatim, and stops on any discrepancy.

**The 97 columns are set by the coverage filter, not by `dropna`.** `dropna(how="any")` — line 57
of the delivered fetcher — drops *dates*, not tickers, and on this panel it drops none. The rule is
`cov >= MIN_COVERAGE` at line 56. The chain, recounted from `data/reference/R15/Priorite_25b_fetch_yf_panel.log` by `tests/test_R15_claims.py` line by line:

| step                 | count  | why                                                                                  |
| -------------------- | ------ | ------------------------------------------------------------------------------------ |
| listed in `UNIVERSE` | 103    | a fixed liquid US large-cap list                                                     |
| unique               | 102    | `QCOM` appears twice; `dict.fromkeys` dedupes **in order**, fixing the column order  |
| fetched              | 100    | `MMC` and `K` exhaust `MAX_RETRY` ("possibly delisted; no timezone found")           |
| retained             | **97** | `V` (4 347/5 154 = 84.3%), `MA` (4 803 = 93.2%), `GM` (3 673 = 71.3%) fall under 98% |
| dates                | 5 154  | the row-wise `dropna` removes none                                                   |

**The silent drop is removed (§S4.3).** The delivered `fetch_one` returns `None` after retry and
`main` skips it with a bare `if s is not None`. `K_max` is the **last element of the published
`K_GRID`**, so a transient network outage silently rewrites the grid of the published figure. This
port names every failure with its exception class and coverage, compares the retained header to the
committed panel, and `sys.exit(1)` on any difference.

**The network path was run once, and the chain reproduces.** On 2026-08-11, seven months after the
submitted fetch, `--stage ingest` returned the *same* two abandonments (`MMC`, `K`), the *same*
three coverage failures at the *same* row counts, and the *same* 97 columns in the *same* order over
the *same* 5 154 dates. The **values** differ by at most `2.16e-06` in absolute log-return — the
provider restating history — which is why the committed CSV is the frozen input and why the ingest
branch verifies and refuses to overwrite it. Elapsed: `4 min 18 s` at the delivered pacing.

**Survivorship is specification, and it cuts against the manuscript's own thesis.** `UNIVERSE` is a
list of currently-listed large caps applied backwards to 2005, so the panel is survivorship-biased
by construction — v87 says so twice. The bias *inflates* co-movement, which makes `ρ̂` an upper
bound and the escape it prices optimistic.

## The entropy: the composition is frozen, the Monte-Carlo migrates

`assets_idx` selects **which real series enter the experiment** — the same category as R01's four
ETFs, R16's four streams and R14's 106 onsets, none of which is redrawn. It is carried verbatim, including the `% (2**32)` truncation the migration otherwise exists to remove. It is **not** exempted by §S6's sharing rule: that clause covers analytic constants of the apparatus, and `assets_idx` is a uniform draw over subsets of size `K`. Invoking it here would licence freezing any inconvenient draw later.

| draw                          | treatment    | key                                |
| ----------------------------- | ------------ | ---------------------------------- |
| `assets_idx`, per `K`         | **verbatim** | as delivered                       |
| `lambda_naive` calibration    | migrated     | `("naive_calib", k_index)`         |
| bootstrap calibration windows | migrated     | `("boot_calib", k_index, i)`       |
| held-out FPR windows          | migrated     | `("fpr_window", k_index, i)`       |
| H1 race windows               | migrated     | `("race_h1", k_index, c_index, i)` |
| H1 single-stream reference    | migrated     | `("race_h1_ref", c_index, i)`      |

Keys carry **integer grid indices**, never the float `c`, never the value of `K`, never
`MASTER_SEED`.

**The consequence is stated before any result is read.** `rho_sign_meas`, `K_eff_meas`, `K_eff_ana`
and `ljungbox_p_Pt` carry no RNG once the composition is fixed and are **guaranteed** to reproduce.
A guaranteed agreement is evidence of port fidelity and of nothing else: it says nothing about the
sampling behaviour of `ρ` or `K_eff`, whose only draw was frozen before the campaign began. The
epistemic-asymmetry rule applies at full force, which is why control C1 asserts the **integer**
composition and holds the four floats to a bound derived from the mechanism.

**One pairing the migration deliberately breaks.** In the delivered script the reference-arm seed
string and the panel-arm string at `K = 1` are the *same string* on the *same* sub-panel, so the
submitted `budget_reduction(K = 1)` is exactly `1.0` by construction. The migrated keys separate
the two roles, so the regenerated `K = 1` cell is an honest estimate of 1 with sampling error
(`0.9902`, `0.9986`, `0.9785`, `0.9965`). No published aggregate reads `K = 1`.

Every gate is stated with its firing probability under **its own** null, never under the witness's
numbers. **No gate rests on a continuous Monte-Carlo value.** The delivered `Control (c)` — which
`sys.exit(1)`s when `FPR_boot` leaves `[0.03, 0.07]` — is **removed as a gate** for exactly that
reason: gating a campaign on a redrawn continuous quantity turns the band into an instrument of
selection over seeds. It is measured, logged and reported at every `K`, and all ten sit inside it.

## Control design under §S4bis

**The window population is finite and small, and every design effect follows from it.**
`H_ref + H_det = 1250` on `T = 5154` days admits exactly **3 905** distinct window starts. The
20 000 calibration draws therefore enumerate that population about **5.1 times over**, and two
windows can share up to 1 249 of their 1 250 days. The calibration and evaluation sets are disjoint
*in seed* and drawn from the *same* 3 905 windows.

**C3: the `√2` rule is not imported, and no fixed multiplier replaces it.** R04b established a
variance doubling for `n_cal = n_eval`. Here `N_CAL = 20 000` and `N_RACE = 2 000`, so the
first-order delta-method multiplier would be `√(1 + n_r/n_c) = 1.0488`, not `1.4142` — and §S4bis's
fifth corollary forbids importing R04b's rule un-re-derived in any case. **Neither multiplier is
correct**, because the uncertainty here is not Monte-Carlo: the two sets overlap in *data*. What is
published is `SE = √(deff_r·p(1−p)/n_r + deff_c·α(1−α)/n_c)` with both effects measured on the
`t_start`-ordered exceedance indicators. Measured `deff_eval` ranges `7.5`–`53.1` and
`deff_calib` `65`–`505`; the resulting `SE` is `0.017`–`0.051`, against `0.0069` from the literal
`√2` rule and `0.0049` from the bare binomial. **It gates nothing.**

**C4: the KS substitute has no `Uniform(0,1)` null on this design.** The ten p-values come from
nested-in-distribution asset subsets of one panel over one common index — the `K = 5` subset is
drawn from the same 97 series as `K = 97` — so they are strongly dependent and a KS test against
`U(0,1)` tests a null that does not hold even under perfect whiteness. The statistic is computed
and persisted with that sentence attached and **is never a gate**. The publishable statistic is the
switch point, which is RNG-free.

**C8: the pooled sign correlation ships without an interval, and that is the design effect
applied.** `\RFifteenRhoSign` pools nine cells whose compositions are all subsets of one 97-asset
panel, with mean pairwise Jaccard overlap `0.2235` (range `0.0000`–`0.7732`). Every pair is
dependent by the mechanism, so the lag count is the full eight. The macro therefore ships as a
point statistic with its dispersion — min `0.2536`, max `0.2881`, s.d. `0.0104` — and **no
interval**, because an interval over cells this dependent would advertise precision the design does
not hold.

**No bare `√n`.** `tests/test_R15_claims.py` scans the executable source for
`np.sqrt(len(...))` and requires a design effect in the same block above it.

## The attribution arm

`--witness-blas` removes `MKL_CBWR` from the environment **before NumPy loads** — the variable is
read once, when the BLAS loads, so an assignment after `import numpy` is inert and argparse is far
too late — and keeps the four thread pins, which is exactly the environment the submitted campaign
ran under. It runs unconditionally and its outputs certify no v87 value.

What it settles: with `MKL_CBWR` removed, `rho_sign_meas`, `K_eff_meas`, `K_eff_ana` and
`ljungbox_p_Pt` are **bit-identical to the submitted campaign at all ten `K`**. The residual on the
default arm is therefore the BLAS instruction-set constraint and not this port. Between the two
arms, `R15_race_windows.csv` (every `t_start` and every delay), `R15_covid_natural.csv`,
`R15_panel_composition.csv` and the figure are byte-identical, and every published race column —
`DetRate`, `ADD`, `SEM`, `ADD_single`, `budget_reduction`, `add_reliable` — is identical to the
last bit. Only the design-effect columns move, at `≤ 2.6e-13`, because the Kish estimator uses
`np.dot`.

`experiments/common/fair_env.py` is shared by every stream and is **not** touched;
`legacy_blas=True` does not serve here, since it lifts the thread pins as well and the submitted
campaign ran with them.

## Limitations

**The caption's composition attribution is confounded with `K` and is not testable here.** The design draws exactly one composition per `K`, so moving along the abscissa changes panel size and membership together. No composition-resampling arm is added: v87 describes none and the scope filter excludes it.

**`add_reliable` does not propagate to the reference arm.** At `c = 0.10` the single-stream reference itself detects at `0.6115`, below the `0.90` floor, so `ADD_single` is censored — a mean over the detected subset of a cell that mostly does not detect — and all eight cells inheriting it are nonetheless flagged reliable. Reported, not repaired; it does not touch the published `c = 0.25` macro, whose reference arm detects at `0.9995`.

**`K_eff ≈ 3.8` is `1/ρ̂`, not the measured `K_eff`.** `1/ρ̂ = 3.8314`; `K_eff_meas` at `K = 97` is
`3.7370`. The gap is the finite-panel term, not a discrepancy, and the caption's `≈` covers it.

**The realized reduction exceeds the reference line the delivered figure draws.** The plateau
`2.0299` exceeds `√K_eff = 1.9331` at six of ten plotted cells and never approaches
`K_eff = 3.7370`. The caption's literal bound holds; its figure's own reference line does not bound
the curve.

**Two primitives the prompt names have no call site in v87's scope.** `simulate_panel` and
`standardized_t` serve the `--source synthetic` branch, which produces Figure 29 — not in v87. They
are pinned by SHA-256 and not quoted, which is §S4.2's treatment for a superseded routine, and the
over-specification is reported rather than settled.

**The panel is survivorship-biased by construction** and the network path is a one-off that no
determinism claim covers.

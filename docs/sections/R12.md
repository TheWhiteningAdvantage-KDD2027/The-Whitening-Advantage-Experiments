# R12 — Volatility misspecification and moment singularity

R12 reproduces v87 **Figure 12** (`fig:leverage`, L585) and **Figure 13** (`fig:fat_tails`, L592) with their paragraphs L349 and L353 under the repository 128-bit seeding policy.

**Experiment A (leverage misspecification).** GJR-GARCH(1,1) with `γ_lev ∈ {0.00, 0.02, ..., 0.28}` (15 points), 10 000 streams per point, `n = 7 000`, pseudo-Gaussian innovations (`ν = 100`). Baseline standardises with symmetric filter `α_sym = α + γ_lev/2`; Concept monitors sign stream at fixed threshold `λ_C = 10`.

**Experiment B (moment singularity).** GARCH(1,1) with standardized Student-`t` innovations, `ν ∈ {10, 9, ..., 4.01}` (16 points), 1 000 streams per point, `n = 10 000`, drift `c = 1.0 σ`. Data CUSUM threshold `λ_iid · Γ = 65 × 2.2208 = 144.35`; Concept CUSUM threshold `λ_C = 10` (no multiplier).

**Result: Both paragraphs reproduce qualitatively. No D3.** Baseline Ljung–Box rejection climbs `5.4 % → 24.2 %`, FPR `3.5 % → 20.5 %` across leverage grid; Concept holds flat `7.4 %–8.5 %`. Detection decays monotonically on reliable domain, collapses below 50 % censoring threshold at exactly `ν ≤ 5.5`; Concept delay stays flat `34–38` steps. Ten of twenty numerals shift at v87 precision (**D2**, `R12-campaign-redraw`); six D1, four structural D0.

**Key design fact.** `simulate_gjr_garch` draws innovations before variance recursion, so `sign(ε_t) = sign(z_t)` exactly. With fixed `ν` and `n` across grid, role-and-index-only keys make Experiment A sign stream bit-identical at all fifteen `γ_lev`. Published on that arm, "leverage-invariant" would be mechanically true. R12 therefore runs **two Concept arms** and publishes only the one whose key breaks the pairing.

C8 asserts CRN degeneracy: 50 seeds × 15 `γ_lev`, SHA-256 of `(ε[2000:7000] > 0)` identical per seed — 750 pairs, 50 distinct digests, `sys.exit(1)` otherwise. Design effect of exactly 15 on 15-point grid is arithmetic signature of one number repeated. `R12_concept_crn_witness.csv` carries that number fifteen times; `supports_published_claim = False` on every row; **no macro, figure point, or interval reads it**.

Data arm is *not* degenerate on either key (symmetric filter reads `ε²_{t-1}` through variance recursion, which carries `γ_lev`), so pairing sharpens Data comparison (`deff = 9.11` vs `0.95`). Key carries grid **index** (integer), never float value → no platform formatting dependency.

**Fourth-moment boundary.** `E[ε⁴] < ∞` iff `α²·3(ν−2)/(ν−4) + 2αβ + β² < 1` → `ν* = 4.0811` at `(α, β) = (0.05, 0.85)`. **Only `ν = 4.05, 4.01` beyond it**; detection collapse begins near `ν = 5.5–6`. Repository policy forbids mechanism attribution. `R02c-mechanism-constraints` records identical shape on i.i.d. arm (infinite eighth moment up to `ν ≤ 8`, effect gone at `ν = 7`) under same ruling. R12 cross-references, invents nothing.

**Threshold asymmetry.** `compute_gamma_exact(0.05, 0.85) = 2.2208` → Data CUSUM `65 × 2.2208 = 144.35`; Concept CUSUM `10` (no multiplier). That asymmetry is what Figure 13 demonstrates.

**R12's negative witnesses.** Cells actually run: `γ_lev = 0` (symmetric filter correctly specified, baseline holds level: `3.46 %` FPR, `5.41 %` Ljung–Box) and `ν = 10` (fourth moment finite, Data detects `82.5 %`). Both measured, both in published CSVs, both classified against v87.

**Variance clamp never binds.** `simulate_gjr_garch` caps `σ²_t ≤ 10⁴ · σ²_unc`. Measured on 6 200 streams (200 per grid point, both experiments, each asserted bit-identical `ε` to primitive): **0 clamped steps of 52 993 800**. Degraded-path hypothesis excluded by measurement, not inspection.

**Open question.** v87 L349 calls `α_sym = α + γ_lev/2` the symmetric GARCH(1,1) "population limit". Design gives **mean-matching**: under symmetric innovations, `E[h_t]` matches `E[σ²_t]` exactly. QMLE population limit is Gaussian pseudo-true parameter [Bollerslev & Wooldridge, 1992]. **Two need not coincide; no R12 measurement decides which `α_sym` is** (witness substitutes `α + γ_lev/2` in closed form). Requires QMLE arm, outside v87 scope.

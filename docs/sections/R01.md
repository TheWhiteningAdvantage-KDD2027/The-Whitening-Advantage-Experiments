# R01 — Real World Backtest (In-The-Wild)

R01 evaluates the structural latency of variance-normalized drift detectors against a strictly calibrated concept-drift monitor over four heteroscedastic ETF streams (SPY, PFF, VNQ, BWX) spanning January 2000 through July 2025. The theoretical basis is the whitening proposition: for a martingale difference sequence, the sign stream is whitened by construction while variance-normalized magnitudes retain temporal dependence. This produces two qualitatively distinct monitoring regimes: a variance-based CUSUM detector that suffers structural latency under heteroscedasticity, and a sign-based concept-drift monitor that maintains calibration at the nominal level.

## Execution

The repository provides three execution paths. The default consumes pre-aggregated derived FirstRate data. The `--stage all` option re-ingests raw intraday FirstRate files when available locally. The `--data-source yfinance` flag replicates the full analysis from public Yahoo Finance data with explicit suffixing to avoid overwriting FirstRate artefacts.

```bash
bash run_experiment_R01.sh            # default: FirstRate, stage=analyse
bash run_experiment_R01.sh all        # re-ingest raw FirstRate tapes (requires the vendor files)
bash run_experiment_R01.sh --data-source yfinance  # public data replication
```

## Expected Artefacts

Seven CSV files in `results/R01_real_world_backtest/data/` capture GARCH model calibrations, COVID-19 CUSUM trajectories and alarms, 2020 symmetry diagnostics, and injection study results. Figure 2 is rendered as `fig02_spy_in_the_wild.png`. The `R01_claims.tex` file provides 25 LaTeX macros for direct inclusion in the manuscript, all of which are unchanged from the submitted campaign.

## Numerical Agreement with the Submitted Campaign

All published numbers are reproduced exactly. The sole identified drift is a D0-level deviation in the variance target (omega and sigma_unc) of at most 2.7e-14 in relative terms, which affects no published quantity and leaves every macro in `R01_claims.tex` unchanged. The Concept arm trajectory is bit-identical; the Data arm peak rounds to the same published value. Reproducibility is certified under single-threaded BLAS and PYTHONHASHSEED=42, producing byte-identical outputs across runs.

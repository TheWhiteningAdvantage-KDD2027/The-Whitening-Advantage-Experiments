### Stream Overview & Mathematical Target

R01 implements the real-world backtest of the whitening calibration framework on four ETF time series (SPY, PFF, VNQ, BWX). The mathematical target is to demonstrate that concept drift detection via CUSUM monitors applied to GARCH-whitened sign streams maintains nominal Type-I error under heteroscedasticity while preserving power against variance shifts. GARCH(1,1) QMLE calibration estimates the unconditional variance `sigma_unc` and persistence parameters `(alpha, beta)` which define the whitening bound `gamma_hat`. The sign symmetry assumption is verified via Ljung–Box tests on the whitened stream `(r_t > 0) - q_hat`.

### Execution & Verification

The pipeline enforces strict determinism via `enforce_strict_determinism()` before any numerical library import, with `PYTHONHASHSEED=42` pinned by the shell. Single-threaded BLAS/MKL is guaranteed through environment variables `OMP_NUM_THREADS=1`, `MKL_NUM_THREADS=1`, `OPENBLAS_NUM_THREADS=1`, and `MKL_CBWR=COMPATIBLE`. All CSV artifacts are serialized with `float_format='%.17g'` via `save_fair_csv`. The test suite verifies GARCH parameter invariance, CUSUM trajectory peaks, injection detection rates, placebo controls, and symmetry properties against baseline values with ULP-budgeted tolerances where applicable.

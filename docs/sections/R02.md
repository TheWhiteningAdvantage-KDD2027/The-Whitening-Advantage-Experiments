### Stream Overview & Mathematical Target

R02 evaluates the Ljung-Box whiteness test under the core whitening proposition: concept drift detection on binary error streams maintains nominal Type-I error even when the underlying data exhibits strong autocorrelation. The experiment generates GARCH(1,1) processes with Student-t7 innovations across three regimes: IID (Gamma=1), Calibration A (Gamma range [3.90, 8.32]), and Calibration B (Gamma range [31.94, 110.49]). The GARCH penalty factor Gamma quantifies long-run variance inflation via the formula `gamma = (1 + 2*rho_1)/(1 - phi)` where `phi = alpha + beta` and `rho_1` is the first-order autocorrelation of squared innovations.

### Execution & Verification

The pipeline executes 360 independent stationary streams (4 ETFs x 30 seeds x 3 regimes) with 8000 steps each. A HoeffdingTreeClassifier predicts the sign of the next return using lagged values and rolling volatility. The Ljung-Box test with 20 lags at alpha=0.05 is applied to both squared GARCH innovations (data drift) and binary classification errors (concept drift). Strict determinism is enforced via `enforce_strict_determinism()` before any numerical library import, with `PYTHONHASHSEED=42` pinned by the shell. 128-bit seeding ensures zero seed collisions across all streams. Single-threaded BLAS/MKL is guaranteed through environment variables. The test suite verifies stream counts, classifier integrity, data and concept rejection rates, distinct p-value counts, independence diagnostics via KS test on Pearson p-values, i.i.d.-arm rejection rate bounds, Wilson interval coverage of pooled concept rejection, and maximum clustered p-value bounds.

### Output Artifacts

Generated artifacts include the raw stream data (`R02_ljungbox_360streams.csv`) containing 360 rows with regime, ETF, seed, GARCH parameters, gamma penalty, Ljung-Box p-values for data and concept drift, error rates, and classifier version; independence diagnostics (`R02_independence_diagnostics.csv`) with 18 Pearson correlation tests across ETF pairs per regime; LaTeX macros (`R02_claims.tex`) defining all published quantities; and Figure 1 (`fig01_ljungbox_whiteness.png`) showcasing the empirical evaluation of the whitening proposition with two panels: (A) Ljung-Box p-values for squared returns, and (B) Ljung-Box p-values for binary errors.
